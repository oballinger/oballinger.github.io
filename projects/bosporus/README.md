# Bosporus frozen-transponder story — servable site

One narrative page with live figures, built from GhostShip experiments `o-21` `o-23`
`o-24` `o-25` `o-26` `o-28` and the `straitwatch` monitor.

## Source of truth

`body.md` — Quarto-flavoured markdown (fenced divs, `{{< include >}}`, raw-HTML blocks).
Edit that. Two render paths read it and must both keep working:

| path | command | needs |
|---|---|---|
| Quarto | `quarto render index.qmd` | quarto (not installed on mbp1/ce-ai-1) |
| plain Python | `python code/build.py` | `markdown` (pip) |

`code/build.py` renders `body.md` + `code/template.html` + `code/site.css` → `index.html`.
`code/build_roster.py` regenerates `interactive/gemstone_roster.html` from `data/*.csv`;
`code/build_maps.py` regenerates the three Leaflet maps from `build/*.json` + the o-23/o-26 results.
`dslr.md` is generated by `build.py`; do not edit it.

## Adding the shore photographs

Drop the DSLR frames into `figures/dslr/` (jpg/png) and re-run `python code/build.py`.
The DSLR slot switches from the placeholder to a gallery automatically.

## Serving

```
./serve.sh 8951
```

Public URL is fronted by the cloudflared tunnel on mbp1 — see the ingress block in
`~/.cloudflared/config.yml` on that machine.

## Layout

```
index.qmd            quarto entry point (includes body.md)
body.md              the article
index.html           rendered output (committed to the served dir, not to git)
code/                build.py, build_roster.py, template.html, site.css
figures/             static PNG/JPG
figures/dslr/        drop shore photographs here
interactive/         self-contained leaflet / folium / SVG figures, iframed
crossing/            webcam episode-picture gallery + supercuts (index.html, manifest.json)
data/                the CSVs the roster table is generated from
```
